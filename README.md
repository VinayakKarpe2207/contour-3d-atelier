# ✒️ CONTOUR — Dimensional Graphite & Sumi-e Atelier

> **Where Classical Draughtsmanship & Zen Calligraphy Meet Third-Dimensional Space.**  
> An interactive WebGL exhibition of 20 master studies across two curated volumes: procedural 3D graphite sketches and Japanese Sumi-e ink brush calligraphy.

---

## 🌟 Overview

**CONTOUR** reimagines the boundary between flat paper draughtsmanship and spatial computer graphics. Uniting two transcendent artistic traditions:
1. **Volume I • Renaissance Graphite Codex**: Inspired by Leonardo da Vinci’s *Codex Atlanticus* and Albrecht Dürer’s geometric engravings, featuring linear perspective, construction scaffolding, and kinetic volume.
2. **Volume II • Sumi-e Zen Ink Codex**: Ancient Japanese ink wash painting (*Suibokuga*) where mindful calligraphic brush sweeps capture the vital spirit (*Ki / Qi*) of nature through calligraphic tapering, flying-white texture (*Hihaku*), and the philosophy of negative space (*Ma*).

Every single curve, bamboo node, crane wing feather, gear tooth, and ink wash ripple is **100% procedural**—sculpted directly in code using Three.js mathematical splines without downloading any external 3D models.

---

## ✨ Key Features

- **🏛️ 20 Bespoke Master Studies across 2 Volumes**: Spanning Renaissance engineering, sacred geometry, Japanese flora & fauna, and Zen Buddhist architecture.
- **🏮 Two Curated Exhibition Wings**: Seamless volume switcher toggles between Renaissance Cotton Parchment and Japanese Washi Paper (`#F5EFE6`) with an authentic red cinnabar artist Hanko seal stamp (水墨).
- **✏️ 4-Stage Live Re-Sketch Animation**: Watch drawings materialize stroke-by-stroke in real-time (*Guides → Contours → Details → Cross-Hatching / Ink Wash*) with synchronized tactile audio.
- **📐 2D Perspective Alignment**: Discover the precise orthogonal viewing angle where 3D spatial curves collapse into a flat, graphic 2D sketch silhouette.
- **📏 Volumetric Cross-Hatching & Ink Bleed Toggle**: Switch layered diagonal pencil shading or ink bleed strokes on and off to analyze how strokes sculpt volume.
- **🎧 Procedural Web Audio API Sound**: Tactile graphite/brush-on-vellum friction and harmonic perspective chimes synthesized mathematically in real-time—no external `.mp3` files needed.
- **🖌️ Freehand 3D Sketch Studio**: Hold and drag across the canvas to sculpt your own continuous wire ribbons floating in 3D coordinates.
- **⚡ Zero Build Step / Instant Loading**: Built with Vanilla HTML5, CSS3, and Three.js—runs instantly in any browser without `node_modules` or bundlers.

## 🚀 Quick Start (Run Locally)

Because this project requires no dependencies or build tools, you can run it with any static local web server:

### Option A: Using Python (Recommended)
```bash
# In the project directory:
python -m http.server 8080
```
Open **[http://localhost:8080](http://localhost:8080)** in your browser.

### Option B: Deep-Linking into Any Study
You can navigate directly to any study or volume via URL search parameters:
- **[http://localhost:8080/gallery.html?vol=1&plate=0](http://localhost:8080/gallery.html?vol=1&plate=0)** (Study 01: Blooming Lily)

## 🌐 Deployment

### Deploy to Vercel (Recommended)
1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Add Volume II: 10 Japanese Sumi-e Zen Ink studies"
   git push origin main
   ```
2. Sign in to [Vercel](https://vercel.com) and click **"Import Project"**.
3. Select this repository and leave the framework preset as **Other**.
4. Click **Deploy**. Vercel will host your 3D Atelier with free global SSL!

### Deploy to GitHub Pages
1. On GitHub, navigate to **Settings** &rarr; **Pages**.
2. Under **Branch**, select `main` and root folder `/`.
3. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## 🛠️ Technology Stack

- **Core**: Vanilla HTML5, Vanilla JavaScript (ES6+)
- **3D Graphics Engine**: [Three.js](https://threejs.org/) (WebGL / PCFSoftShadowMap / Catmull-Rom Splines / BufferGeometry)
- **Styling**: Vanilla CSS3 (Custom design system, glassmorphism, SVG cotton grain overlay, authentic Hanko seal stamp)
- **Audio**: Web Audio API (In-memory procedural bandpass-filtered noise synthesizer)
- **Typography**: Google Fonts (*Cormorant Garamond*, *Plus Jakarta Sans*, *Space Mono*, *Noto Serif JP*)
